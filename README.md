# Salon Demo — демо-сайт салона красоты

Демонстрационный адаптивный сайт авторского салона красоты в концепции **warm organic editorial**. Вёрстка на чистом HTML/CSS/JS без сборки, зависимостей и внешних виджетов, кроме шрифтов Google Fonts.

## Структура проекта

```
.
├── index.html    — полный HTML-документ (семантические секции, доступность)
├── styles.css    — дизайн-система: токены, типографика, сетки, адаптив
├── script.js     — вся интерактивность (меню, скролл, формы, тост)
└── README.md
```

Открывается прямым открытием `index.html` в браузере. Сервер не требуется.

## Секции страницы

1. **Header** — фиксированная шапка, лого, навигация, телефон, кнопка «Записаться».
2. **Hero** — полноэкранный блок с фоновым изображением, крупной serif-типографикой, метаданными (часы, адрес-плейсхолдер).
3. **Манифест** — асимметричная сетка 5/7, sticky-заголовок.
4. **Услуги** — редакционный список с номерами и ценами-плейсхолдерами.
5. **Мастера** — три портрета с разным вертикальным офсетом.
6. **Работы** — редакционная галерея с чередованием форматов кадра.
7. **Пространство** — тёмная плоскость с крупным изображением.
8. **Часы и локация** — контактный блок и плейсхолдер карты.
9. **Запись** — демонстрационная форма (услуга, мастер, дата, время, имя, телефон).
10. **Footer** — лого, навигация, демо-политика.
11. **Mobile sticky CTA** — кнопка «Записаться» внизу экрана на мобильных.

## Интерактивные элементы (script.js)

Все обработчики навешиваются через `addEventListener`, без inline `onclick` и без сторонних библиотек.

- **Мобильное меню.** Кнопка `.menu-toggle` с `aria-expanded`, `aria-label` меняются при открытии/закрытии. Закрытие по клику на ссылку, по Escape (с возвратом фокуса) и по клику вне меню.
- **Состояние шапки при скролле.** Класс `is-scrolled` при прокрутке >24px.
- **Активный пункт навигации.** `IntersectionObserver` подсвечивает ссылку текущей секции, выставляет `aria-current`.
- **Reveal-анимации.** `IntersectionObserver` добавляет класс `is-visible` секциям и карточкам. Отключается при `prefers-reduced-motion: reduce`.
- **Демо-форма записи.**
  - Минимальная дата — сегодня.
  - Маска и валидация телефона (11 цифр, формат +7 (XXX) XXX-XX-XX).
  - Проверка обязательных полей: услуга, дата, время, имя, телефон.
  - Ошибки выводятся рядом с полем через `aria-live` и `aria-invalid`.
  - `submit` перехватывается, `preventDefault`. Данные никуда не уходят: показывается статус через `role="status"` и `aria-live="polite"`.
- **Ссылки-плейсхолдеры (`href="#"`).** При клике показывает демо-уведомление (тост), чтобы не было «битых» переходов.
- **Плавная прокрутка и фокус.** После перехода по якорю целевая секция получает `tabindex="-1"` и фокус для скринридеров и клавиатуры.

## Доступность

- Семантические теги: `header`, `nav`, `main`, `section`, `article`, `figure`.
- Все интерактивные элементы доступны с клавиатуры (`:focus-visible` стилизован).
- ARIA: `aria-expanded`, `aria-label`, `aria-current`, `aria-live`, `aria-invalid`.
- Кнопки и поля соответствуют тач-таргетам ≥44px.
- Цветовые контрасты текста на бумажном и тёмном фонах проверены.
- Полное отключение анимаций при `prefers-reduced-motion`.

## Адаптивность

- **Мобильный (<640px):** одноколоночная композиция, фиксированная шапка, sticky-CTA внизу, полноэкранное меню.
- **Планшет (640–879px):** двухколоночные сетки для карточек и формы.
- **Десктоп (≥880px):** горизонтальная навигация, асимметричные split-секции, редакционная галерея 12-колоночной сеткой.
- **Широкий (≥1400px):** увеличенный контейнер.

Горизонтального overflow нет — проверено на всех breakpoint-границах.

## Демонстрационные ограничения

**Важно:** это **демо**, а не рабочий сайт клиента.

- Все данные — плейсхолдеры: `[адрес]`, `[цена]`, `[Имя мастера]`, `+7 (000) 000-00-00`.
- Изображения — сгенерированные SVG-заглушки в базе данных: реальные фотографии появятся после согласования.
- Блок отзывов отсутствует — по брифу, только с реальными подтверждёнными отзывами.
- Форма записи **не отправляет данные**: `preventDefault` + сообщение в демо-режиме. Никаких fetch, XMLHttpRequest, сторонних интеграций.
- Нет реальных цен, акций, лицензий, сертификатов, стажа, брендов средств и оборудования.
- Телефон и ссылка на маршрут — плейсхолдеры.
- Ссылка «Политика конфиденциальности» — демо, показывает уведомление.

## Запуск

1. Скачать папку с `index.html`, `styles.css`, `script.js`.
2. Открыть `index.html` в современном браузере (Chrome, Firefox, Safari, Edge — последние версии).
3. Для проверки на мобильном — открыть через локальный сервер (`python3 -m http.server` или `npx serve`) и зайти по IP в локальной сети.

Никакой сборки, npm-зависимостей и внешних скриптов не требуется. Google Fonts — единственное внешнее подключение (опционально: при желании можно заменить на локальные шрифты).

## Что дальше по брифу (не входит в демо)

Открытые вопросы к клиенту из брифа:

- Сегмент, реальные цены и услуги.
- Реальные мастера, их специализации и согласованные фото.
- Город, точный адрес, часы, телефон, соцсети.
- Формат онлайн-записи: свой wizard или переход на Dikidi/YCLIENTS.
- Наличие и разрешение на использование реальных отзывов.
- Брендовая типографика и фотографии интерьера.

После уточнения этих пунктов прототип превращается в боевой сайт без пересборки архитектуры.
